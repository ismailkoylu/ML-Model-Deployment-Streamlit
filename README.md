# Machine Learning Model Deployment Dashboard (Streamlit)

Bu proje, verilerin keşifsel analizi ve makine öğrenmesi modellerinin (Regresyon ve Sınıflandırma) gerçek zamanlı olarak test edilebildiği interaktif bir web uygulamasıdır.

## 🚀 Proje Özellikleri
- **Dinamik Veri Keşfi:** Veri setinin istatistiksel özetlerini ve ham veriyi inceleme imkanı.
- **Gelişmiş Görselleştirme:** Korelasyon matrisleri, histogramlar ve saçılım grafiklerini içeren interaktif görselleştirme araçları.
- **Linear Regression Modülü:** Sayısal veriler üzerinden bağımlı değişken tahmini.
- **Logistic Regression Modülü:** İkili sınıflandırma (Binary Classification) problemleri için model tahmini ve olasılık hesaplama.

## 🛠 Kullanılan Teknolojiler
- **Framework:** Streamlit
- **Veri İşleme:** Pandas, NumPy
- **Görselleştirme:** Seaborn, Matplotlib
- **Makine Öğrenmesi:** Scikit-learn (Linear & Logistic Regression)

## 💻 Yerel Kurulum
1. Projeyi klonlayın: `git clone [repo-linki]`
2. Gerekli kütüphaneleri kurun: `pip install -r requirements.txt`
3. Uygulamayı çalıştırın: `streamlit run app.py`
