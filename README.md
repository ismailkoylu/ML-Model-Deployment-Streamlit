# Machine Learning Model Deployment using Streamlit

Bu proje, eğitilmiş makine öğrenmesi modellerinin (Sınıflandırma ve Regresyon) web tabanlı bir uygulama üzerinden son kullanıcıya sunulmasını sağlamaktadır.

## Özellikler
* **Model Entegrasyonu:** Daha önceden eğitilmiş Scikit-learn modellerinin uygulama içerisine dahil edilmesi.
* **İnteraktif Arayüz:** Kullanıcının veri girişi yapabildiği ve anlık tahmin (prediction) sonuçları alabildiği Streamlit arayüzü.
* **Görselleştirme:** Tahmin sonuçlarının ve veri istatistiklerinin grafiklerle sunulması.

## Kullanılan Teknolojiler
* Python
* Streamlit (Web Arayüzü)
* Scikit-learn (ML Modelleri)
* Pandas

## Kullanım
Uygulamayı yerelde çalıştırmak için:
```bash
pip install -r requirements.txt
streamlit run app.py
